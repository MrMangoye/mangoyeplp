# 🎉 Fun Calculator 😎

Welcome to the **Fun Calculator**, a quirky little Python program that makes basic math feel like a party 🎈. It adds, subtracts, multiplies, and divides two numbers with style and emoji flair!

## 🚀 Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division (Just don’t divide by zero...please! 😅)
python Calculator.py
🤔 Why This Project?
Just a fun way to learn Python basics and make math a little more exciting. Ideal for beginners who want to spice up their first coding experience.
💡 What's Next?
Want to expand the calculator? Try adding:
- Error handling for division by zero
- Operations with more than two numbers
- A graphical user interface (GUI) with tkinter
